# Student Grade Calculator

Takes marks for multiple subjects (stored in an ArrayList) and prints the total, average percentage and grade.

Built for the SAM AI Technologies Java Programming Internship.

## How to run

You need JDK 8 or newer.

```
javac StudentGradeCalculator.java
java StudentGradeCalculator
```

## Notes

- Grade rules: A >= 80%, B >= 60%, C >= 40%, below 40% is Fail.
- Marks must be between 0 and 100.
